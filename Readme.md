# 🌐 Personal Portfolio Website

A modern, responsive, and sleek developer portfolio built using HTML5, CSS3, and JavaScript. Designed with a dark-themed glassmorphism UI to showcase projects, core technical skills, and professional experience.

## ✨ Features

* **Modern Glassmorphism UI:** Clean dark theme with smooth gradients, cards, and hover effects.
* **Responsive Navigation:** Fully functional hamburger menu for seamless mobile viewing.
* **Project Filtering:** Interactive filter tabs to easily sort projects by category (AI, Python, Web).
* **Direct Connect Links:** Quick access links to GitHub, LinkedIn, and direct email communication.

## 🛠️ Core Skills

* **Programming & Web:** Python, SQL Databases, HTML & CSS Basics
* **Data Science & AI:** Streamlit & NLP, Pandas & NumPy, Scikit-learn (Machine Learning)
* **Tools & Workflow:** Git & GitHub, Matplotlib & Seaborn, VS Code Studio

## 🚀 Featured Projects

1. **FitAI Pro:** An AI-powered fitness planner providing personalized meal & workout recommendations, image analysis, and interactive dashboard analytics using Python, Streamlit, and NLP.
2. **LPDG Innovation Hub–Gateway Visit Prioritization 2026:** A machine learning model developed to prioritize and manage site visits effectively using Pandas and Scikit-learn.

## 💻 Tech Stack

* **Frontend:** HTML5, CSS3 (Custom Styles & Flexbox/Grid)
* **Scripting:** JavaScript (DOM Manipulation & Filtering Logic)
* **Icons & Fonts:** FontAwesome & Google Fonts (Plus Jakarta Sans)
